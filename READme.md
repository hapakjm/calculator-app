# Calculator App

A calculator web application developed as a practice project to improve my web development and programming skills.

## Description

This project is a simple Calculator App that I am developing as part of my web development learning journey.

The main goal of this project is to practice and improve my programming skills by building the same application using different web technologies and approaches.

The project will be developed progressively, starting with **JavaScript** and later rebuilding or improving it using **TypeScript** and different frameworks and tools such as **React, Angular, Tailwind CSS, Sass**, and others.

While developing each version, I will practice concepts such as:

- HTML, CSS, and JavaScript fundamentals.
- DOM manipulation and event handling.
- Programming logic and problem-solving.
- TypeScript and type safety.
- Component-based development.
- CSS frameworks and preprocessors.
- Code organization and maintainability.
- Git and GitHub workflow.

Some versions may be based on tutorials, courses, official documentation, or reference projects. I will also make my own changes and improvements to better understand the technologies and apply what I have learned.

This repository will serve as a record of my progress as I improve the Calculator App and my overall web development skills.

## Features

Features may vary between versions as the project evolves.

- Basic arithmetic operations.
- Addition, subtraction, multiplication, and division.
- Decimal number support.
- Clear and reset functionality.
- User-friendly calculator interface.
- Responsive design.
- Additional features and improvements as the project develops.

## Installation

Clone the repository:

```bash
git clone https://github.com/hapakjm/calculator-app.git
cd calculator-app
```

Open the desired project version and run it using your preferred development environment.

For versions that require additional dependencies, follow the installation instructions provided in their respective project folders.

## Design Reference

The initial body design was inspired by [RV App Studios' Smart Calc: Daily Calculator](https://www.rvappstudios.com/smart-calc-daily-calculator-120.html)

The initial button design was inspired by [Calculator - Calculator Plus](https://play.google.com/store/apps/details?id=com.eco.calculator).

The reference was used as a visual guide while creating my own implementation.

Reference images used during development are stored in the `public/` folder.
